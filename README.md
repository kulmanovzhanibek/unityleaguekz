# Unity League — сайт лиги

Статический сайт в стиле Flashscore для **Unity League**: лиги по футзалу 5×5 среди выпускников лицеев Казахстана.
Здесь собраны матчи, результаты, турнирные таблицы, бомбардиры, ассистенты, карточки, календарь, архив сезонов и рекорды.
Все данные взяты из экспорта Telegram-канала [@unityleaguekz](https://t.me/unityleaguekz) с 2017 по 2026 год.

## Что есть на сайте

| Раздел | Содержимое |
|---|---|
| **Матчи** | лента туров (как на Flashscore) с матчами выбранного тура; для турниров, где туры восстановить нельзя, — лента игровых дней |
| **Результаты** | все матчи турнира по игровым дням, есть фильтр по команде |
| **Таблица** | турнирная таблица с формой команды, тай-брейками и плей-офф (если он был) |
| **Статистика** | бомбардиры, ассистенты, «гол + пас», карточки |
| **Календарь** | сетка по месяцам с матчами |
| **Команды** | карточка каждой команды: титулы, история выступлений, матчи, лучшие игроки |
| **Матч** | хронология с голами, ассистами и карточками по таймам, личные встречи и ссылка на исходный пост в Telegram |
| **Архив** | зал славы (титулы) и карточки всех 16 турниров |
| **Рекорды** | крупнейшие победы, самые результативные матчи, покеры и лучшие бомбардиры сезонов |

Есть тёмная и светлая тема, вёрстка адаптирована под телефон. Сайт не требует сборки и зависимостей.

## Как открыть

- **Локально:** дважды кликните `index.html`. Сайт работает и с `file://`.
- **GitHub Pages:** Settings → Pages → *Deploy from a branch* → ветка `main`, папка `/ (root)`.
  Файл `.nojekyll` уже лежит в корне.
- Подойдёт любой статический хостинг: Netlify, Vercel, Cloudflare Pages и т.п.

## Структура

```
index.html            разметка и шапка
assets/css/style.css  стили (цвета вынесены в CSS-переменные; тёмная тема по умолчанию)
assets/js/app.js      весь интерфейс: роутинг, таблицы, статистика
assets/img/logo.svg   логотип
data/league.js        данные лиги (window.LEAGUE_DATA)
scripts/telegram/     импорт из экспорта Telegram
```

## Обновить данные из Telegram

1. В Telegram Desktop откройте канал → ⋮ → **Export chat history** → формат **HTML**. Медиа выгружать не нужно.
2. Выполните:
   ```bash
   python3 scripts/telegram/run.py ~/Downloads/ChatExport/messages.html
   ```
   Если экспорт разбит на несколько файлов (`messages.html`, `messages2.html`, …), передайте их все по порядку.
   Скрипт перезапишет `data/league.js` и выведет список матчей, которые стоит проверить вручную.

Скрипт понимает все форматы постов канала: от `Griffins 6-2 Aksay (FT)` с `⚽️ 4': Игрок (Ассистент) (1-0)`
до `AKTEL 3:3 SEMEY` с `⚽️10' Дархан Б (Бекжан Т) 1:0`, а также `ЖК`, `⚠️`, `🟨`, `🟥`, автоголы, пенальти и серии пенальти.
Если у гола не указан текущий счёт или в счёте опечатка, команда автора гола определяется по составу,
собранному по остальным матчам сезона.

Новый сезон добавляется в список `T` в `scripts/telegram/build.py`: id, даты, участники, чемпион.
Новые написания команд добавляются в `ALIASES`.

## Формат данных (если правите вручную)

```js
window.LEAGUE_DATA = {
  league: { name, tagline, slogan, points: { win: 3, draw: 1, loss: 0 }, links: { telegram, instagram, youtube } },
  teams: [ { id: "aktel", name: "AKTEL", short: "AKT", color: "#f4a300", logo: "assets/img/aktel.png" /* необязательно */ } ],
  seasons: [ {
    id: "2025-26", season: "2025/26", name: "Premier Division", status: "finished",
    champion: "aqsay",             // если известен официально
    championFromTable: true,       // иначе чемпион = первое место таблицы
    incomplete: true, expected: 66,// если опубликована только часть матчей
    names: { bmg: "BMG Nova" },    // название команды в этом сезоне
    note: "текст под таблицей",
    teams: ["aqsay", "aktel", …],
    matches: [ {
      id: "2025-26-1", d: "2025-11-29", h: "aqsay", a: "zhetisu", sc: [7, 0],
      r: 1,                        // тур (необязательно)
      st: "Финал",                 // стадия плей-офф: такие матчи не идут в таблицу
      pens: [4, 3], tech: true,    // серия пенальти / технический результат
      src: 1292,                   // номер поста в канале → t.me/unityleaguekz/1292
      ev: [ [24, "goal", "h", "Багыжан А", "Амир А"],  // минута, тип, сторона (h/a), игрок, ассистент
            [32, "yc", "a", "Әділет Р"] ]              // типы: goal, pen, og, yc, rc, mp (незабитый пенальти)
    } ]
  } ]
};
```

## Особенности данных

- **Полнота.** Протоколы почти всех матчей опубликованы для сезонов 2017/18 и с 2020/21 по 2025/26.
  В сезонах 2018/19, 2019/20 и в студенческих лигах часть результатов выходила только картинками. На сайте такие турниры отмечены
  предупреждением, а таблицы в них построены по опубликованным матчам.
- **Чемпионы.** Где чемпион назван в канале (AKTEL, EY, Aqsay, Sunkar, Altyn Adam, Aqsay SG, BMG и др.), указан он.
  Для 2021/22, 2022/23 и 2025/26 чемпион в тексте не назван, поэтому указана команда с первого места итоговой таблицы
  (пометка «первое место в таблице»). Счёт финала Super Division 2020 (Qurmet — Vernyi) в канале не опубликован.
- **Названия команд объединены:** Aksay/Aqsay/ASG/Aqsay SG, AKTEL/AKTEL Premix Pro/AFC AKTEL, BMG/BalykMunaiGas/BMG Nova,
  Akzhayik/Aqjaiyq, Spartak Semey/Semey, Zhetisu/Jetisu/Jetysu, Vernyi/Verniy, JezGrads/Jez Grads.
  Название, под которым команда выступала в конкретном сезоне, сохранено в `names`.
- **Туры.** Номер тура канал указывал не всегда. Недостающие номера восстановлены автоматически: в туре каждая команда
  играет один раз, явные отметки «N тур» и «(N tour)» из постов служат опорой, перенесённые матчи попадают в свой тур.
  Для всех полных сезонов Premier Division получился точный круговой турнир (например, 2021/22 — 15 туров по 8 матчей).
  Где это невозможно (Super Division 2017/18, студенческие лиги, неполный 2019/20), матчи сгруппированы по игровым дням.
- **Имена игроков** приведены так, как они написаны в постах. Разные написания одного игрока в пределах сезона
  (порядок слов, казахские буквы, «Данияр О.» ↔ «Данияр Олджамурат») объединены. С 2024 года канал пишет имена
  в формате «Имя Ф.», поэтому в последних сезонах имена короткие.
